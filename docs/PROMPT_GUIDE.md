# Prompt 撰寫指南

規則解析器以「零件類型 → 主尺寸 → 孔群 → 邊特徵」為優先。尺寸可用 mm、cm、公分、m、inch／英吋，內部統一轉成 mm。

## 建議格式

```text
[材料] [零件類型]，長/寬/高/厚/外徑/內徑，孔數、孔徑或 M 規格、孔型、孔位、孔深，圓角/倒角。
```

範例：

```text
鋁合金固定板，長120mm、寬60mm、厚10mm，四角 M6 通孔，孔中心離邊10mm，垂直邊 R5。
```

## 主尺寸

- 板件：`長120、寬60、厚10`
- 三聯尺寸：`120x60x10 mm`
- 圓柱：`直徑30、高50`
- 圓環：`外徑30、內徑15、厚5`
- L 支架：`寬80、深50、高60、厚4`
- 外殼：`100x70x30 mm，壁厚2`

## 孔

```text
兩個直徑5mm通孔
四角 M6 通孔，邊距10mm
中央一個直徑5mm、深6mm盲孔
兩個5mm沉頭孔，沉頭徑10mm，角度90度
兩個5mm沉孔，沉孔徑9mm，沉孔深3mm
立板兩個 M5 孔
```

M 規格未指定攻牙時會視為一般間隙孔；加入「攻牙／牙孔／tapped」才會採用攻牙底孔近似。

## 軸方向

- 一般底板／板件孔：預設 `Z` 軸。
- L 支架「立板孔」：解析為 `Y` 軸。
- 也可明確寫 `X 軸孔`、`Y 軸孔`、`Z 軸孔`。

## 明確座標

單一規則孔群支援座標：

```text
直徑5mm孔，x=20mm, y=-10mm
```

複雜的多孔群、不同孔徑或多組座標，建議使用 LLM planner，再在 Web 的 DSL 編輯器逐孔調整。

## 外殼矩形側面開口

```text
做一個94x58x22mm外殼，壁厚2mm，+Y面一個14x8mm矩形開口，中心x=25mm、z=9mm
```

側面可寫 `+X面`、`-X面`、`+Y面`、`-Y面`，也支援英文 `positive x`、`negative x`、`positive y`、`negative y`。尺寸依序為側面水平寬度與垂直高度；未指定 `z` 時預設置中並列入 assumptions。

## 減少歧義

- 不要只寫「做一個支架」；至少提供 2～4 個主尺寸。
- 將孔徑與孔深都加上關鍵字，例如「直徑5、深6的盲孔」。
- M6 是螺紋名目尺寸，不等同所有用途的 6 mm 鑽孔；寫明「M6 攻牙」或「M6 間隙孔」。
- 加工前檢查 `assumptions`、`validation.issues` 與 `review_required`。
